# 위플 가계부 리포트 생성기 (WepleReport)

위플 가계부(Weple Money, iOS) 앱의 **Export CSV File** 결과를 읽어, 가계
현금흐름을 왜곡하는 항목을 보정한 **월별 리포트(단일 HTML, 차트 내장)** 를
만들어 줍니다.

## 빠른 시작

```bash
# (선택) 차트용 의존성 — 없어도 표 막대로 동작합니다
pip install matplotlib koreanize-matplotlib

# CSV 안의 모든 달
python weple_report.py weple_20260530.csv

# 특정 달만
python weple_report.py weple_20260530.csv -m 2026-04 2026-05 -o report.html
```

생성된 `report.html` 은 이미지·스타일이 모두 내장된 **단일 파일**이라 그냥
브라우저로 열거나 카톡/메일로 공유하면 됩니다. (모바일 반응형)

## 무엇을 보정하나

위플은 자산 이동(이체)을 별도 처리하지 않으면 다음이 **이중 계산**됩니다.
이 스크립트는 아래 규칙으로 보정합니다.

| # | 항목 | 처리 |
|---|------|------|
| 1 | **카드대금 납부** | 자산이동(이체)으로 보고 소비에서 제외 |
| 2 | **페이코(복지포인트)** | 회사 복지비 → 가계 현금과 분리한 '별도 장부'로 집계 |
| 3 | **충전형 페이카드**(용인·화성·수원페이 등) | 충전은 이체, **실제 사용액만** 소비. 잔액은 자산 |
| 4 | **이중 입력** | `DEDUP` 목록의 중복 거래 1건 제거 |

→ 결과 지표 **실가계소비 = 현금 + 신용카드 + 충전카드 실사용**.
통과성 거래(대신 결제 후 송금받음)는 **자동 상쇄하지 않고 주석으로만** 표시합니다.

## 내 가계에 맞게 고치기

`weple_report.py` 상단의 **CONFIG** 영역만 수정하면 됩니다.

- `REGULAR_INCOME` — '정기수입'으로 볼 분류 (기본: 월급, 아동수당)
- `PAYCO_ASSETS` / `is_payco_income` — 복지포인트 자산·지급 판별
- `is_charge` — 충전(이체) 거래 판별 규칙
- `DEDUP` — 수동 중복 제거 목록 `(거래일, 내역, 금액)`
- `SAVING_CATS` — 자산형성(저축·청약·투자)으로 참고 표시할 분류

## CSV 컬럼 구조 (참고)

위플 Export CSV(UTF-8 BOM, 콤마 구분, 10열):

```
사용자, 거래일, 수입/지출, 금액, 분류, 하위 분류, 내역, 지불, 카드, 메모
```

- `거래일` `YYYY-MM-DD` · `수입/지출` 수입/지출(/이체) · `금액` 천단위 콤마+따옴표
- `지불` 현금/카드/체크카드(결제수단 종류) · `카드` 실제 자산명(현금/○○카드)
- 금액은 부호 없이 항상 양수 → 수입/지출은 `수입/지출` 열로만 구분
